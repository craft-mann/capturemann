## Findings not fixed (for the lead)

1. **Wayland keeps the Studio window's own title bar and places windows itself**: the sheet appears over the Studio window; nothing wrong, but the banner's promise "stop from the tray or the desktop's indicator if this window is hidden" holds (seen both).
2. Settings -> Shortcuts on Wayland: the subtitle and the page promise global shortcuts that do not exist there (item 16).
3. The Permissions page has no Linux explanation (item 13). The first-run text says "Your desktop asks when CaptureMann captures the screen", true only for the portal backend (GNOME's service never asks); changing it needs a new msgid and a vi.po entry (not changed).
4. The sheet and the editor read time and cursor claims that are Mac/Windows only: the confirmation's "Cursor: Position, clicks and scroll direction" on Wayland (item 18).
5. Editor timeline "Screen" lane empty and a truncated "Decoded from the recording wi..." line (item 19).
6. Window recording shows "late frames 30.8 %" (item 21).
7. "Record..." in the library sidebar and the left rail stay clickable and red during a recording (the sheet then answers "A recording is already running").
8. Not run: chime and Play test sound, playback with sound, Reopen setup, a region recording from the sheet, a take with the webcam, the tray's menu, a 700 px wide Studio window, a second monitor.

## Method notes

- Switching the session: `rec-session.sh` needs to be run **twice**: the first run restarts GDM but the new session still starts as the old type (AccountsService is read late); the second gives the new type. Both directions behaved the same.
- `xdotool` clicks on the Studio window after the app starts: the first click only focuses the window.
- Wayland: GPUI ignores touch; `desk-uinput-mouse.py` (committed) works. `capturemann capture screenshot --display 1 --out` is the window-crop source; it puts screenshots in the private library.
- Quick sheet-size diagnosis: `CM_DEMO_SHEET_TRACE=1` now also logs on Linux (`window`, `est`, `overflow`, `extra`).
