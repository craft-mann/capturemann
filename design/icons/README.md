# CaptureMann icon set

143 icons for the CaptureMann desktop app, based on the icon inventory at commit `8618ef8`.

- **15 custom `cm-` glyphs** for CaptureMann-specific ideas: region capture, record/stop, webcam bubble, camera layouts, bubble corners, trim in/out, split.
- **128 Lucide v1.60.0 icons**, the same library and version the app already uses (ISC licence).
- **Two new tray states,** Paused and Attention, for macOS (template) and Windows (.ico).

Start with:

- `preview/icon-set.png` to see the whole set.
- `icon-map.md` for which icon goes where (278 rows, with priority and size).
- `CLAUDE.md` for the rules, sizes and how to wire the icons in (written for a coding agent).
