# Project status

A dated log of what is built and how it was checked, kept out of `CLAUDE.md` so that file stays a short guide. The delivery plan is [`plan.md`](plan.md); the open verification work is in `specs/04-delivery-plan.md` (**Verification debt**).

Release 0.2.0 (voice and meetings) and later releases up to 0.2.7 are published (see their sections below); Windows 0.2.8 is published (Nov 6, 2026); 0.2.9 (Windows and macOS) is published (Nov 8, 2026). CaptureMann v0.1 is a free, Apache-2.0, pure-Rust desktop app (v0.1 is macOS 13+ on Apple Silicon only; Intel Macs, then Windows 10 22H2+, then Linux follow, maintainer decision Oct 24, 2026) for screenshots and screen recording (up to native 4K/5K, webcam bubble), with local folders and Google Drive for storage and YouTube for publishing (scope decision Oct 23, 2026: OneDrive and Dropbox are built but "Coming soon"; TikTok and Facebook Pages are deferred; both are open for community contributions, see CONTRIBUTING.md). Every feature is also exposed to AI agents via MCP and a CLI.

The repo is a Cargo workspace (`Cargo.toml`, `crates/*`, `apps/*`; `spikes/` is a separate workspace; `rust-version = "1.95"`). Status as of Oct 21, 2026 (details in `docs/project/plan.md`, `specs/04-delivery-plan.md` including its **Verification debt** section, and each feature file's Status):
