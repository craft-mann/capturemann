# Project status

A dated log of what is built and how it was checked, kept out of `CLAUDE.md` so that file stays a short guide. The delivery plan is [`plan.md`](plan.md); the open verification work is in `specs/04-delivery-plan.md` (**Verification debt**).

Release 0.2.0 (voice and meetings) is built and waiting for the maintainer to cut it; see "Release 0.2.0" and its checklist below. CaptureMann v0.1 is a free, Apache-2.0, pure-Rust desktop app (v0.1 is macOS 13+ on Apple Silicon only; Intel Macs, then Windows 10 22H2+, then Linux follow, maintainer decision Oct 24, 2026) for screenshots and screen recording (up to native 4K/5K, webcam bubble), with local folders and Google Drive for storage and YouTube for publishing (scope decision Oct 23, 2026: OneDrive and Dropbox are built but "Coming soon"; TikTok and Facebook Pages are deferred; both are open for community contributions, see CONTRIBUTING.md). Every feature is also exposed to AI agents via MCP and a CLI.

The repo is a Cargo workspace (`Cargo.toml`, `crates/*`, `apps/*`; `spikes/` is a separate workspace; `rust-version = "1.95"`). Status as of Oct 21, 2026 (details in `docs/project/plan.md`, `specs/04-delivery-plan.md` including its **Verification debt** section, and each feature file's Status):

- **Built (macOS):** `cm-core` (with the edit list and timeline math of EDT-1 to EDT-5), `cm-capture` (screenshots, the screen recording track, disk guard), `cm-camera`, `cm-audio` (capture, plus `mix`: gains, R128 loudness, limiter, pitch-preserving stretch), `cm-cursor` (telemetry capture, plus `view`: the cursor path, smoothing, click effects and the zoom and reframe camera), `cm-encode` (hardware fMP4 writer: VideoToolbox on macOS; no software H.264 fallback, a rejected hardware encoder fails the start with `platform_rejected` / `hardware_encoder_unavailable`), `cm-render` (annotations; Auto-redact's `ocr` module (ANN-2.AC4: the `TextRecognizer` trait, Apple Vision on macOS through `objc2` messages, an unavailable stub on Windows, a scripted fake, and the pure detector for emails, keys and tokens, phone numbers and IPv4 addresses; tested with fakes, and the Vision path ran once on a synthetic PNG in an ignored test); and the headless `wgpu` frame compositor `compose::Compositor` (with the burned-in caption layer), tested with goldens on an Apple M4 Pro, the edit-list export path in `cm-media` feeds it: tested with FFmpeg and a GPU on this Mac, not on CI), `cm-jobs`, `cm-library` (`.cmshot` and `.cmrec` bundles, SQLite index, crash recovery), `cm-daemon` (action bus, JSON-RPC, confirmation gate, per-client policy, settings store, recording engine and self-test, export hook, the library watcher: a 2 s polling scan that indexes bundles added, removed, renamed or edited outside the app and publishes `capture.*` events;
