# Design implementation traceability

Maps every screen and component of the design kit (`design/`, entry point `design/CLAUDE.md`) to the specs that define its behavior, the section of `docs/development/design-surfaces.md` that defines the product surface, and the implementation status. Update the status column in the same change that moves the work. Status values: **Not started**, **In progress**, **Done**.

Status snapshot: Oct 21, 2026, re-checked against the code after the review and fix wave. Repo state: `apps/desktop` has the GPUI shell and Studio window (sidebar, library, light and dark themes), the design tokens and Geist fonts, the kit app icon and tray icons, global hotkeys with a rebinding UI, a single-instance lock, the launcher (LNC-1), the in-app permissions setup screen and Settings → Permissions (PRM-1), the confirmation dialog, toasts, Settings with General, Recording, Agents & CLI (client config, capability list, per-client policy, activity) and Destinations (local folders: list, add, edit, default, remove; Google Drive, OneDrive and Dropbox connect; the publish cards disabled until M6), the annotation editor (ANN-1..3), the start sheet, the recording HUD, the countdown window, the area brackets and `rec` outline, the live bubble and the agent toast. `apps/overlay` has the region picker with the magnifier. All of that UI is unit tested; none of it has a stored hardware verification report, so "built" below means built and tested with fakes, not verified on a real display. Not built: the timeline editor, inspector, video preview, the delayed-capture pill, the Rename and Delete daemon actions the library menu needs. Windows is unverified for everything.

## Native-implementation deviations (accepted)

| Kit rule | Deviation | Reason | Revisit |
| --- | --- | --- | --- |
| Backdrop blur on launcher and HUD | Same fill at 96% opacity, no blur | GPUI cannot blur behind a window | If the framework or an OS vibrancy API becomes usable |
| Letter spacing (-0.045em display, -0.03em headings, +0.04em mono labels) | Zero tracking | GPUI has no letter spacing | Same |
| Multiple font weights | Register each static Geist TTF as its own face | The kit ships Regular, Medium, SemiBold, Bold and Mono Regular, Medium; variable fonts are not selectable by weight in GPUI | n/a |
| Shadows on dialogs and toasts (`shadow.float`, `shadow.hud`) | None; 1 px `line` border only | Toasts and dialogs are opaque windows without shadows | Same |
