### 1. Callout (finishes the ANN-4 draft)
A text box with a tail that points at something, like "Click here to save" with an arrow-shaped tail touching the button. Snagit, CleanShot and ShareX all have one. Today users fake it with a rectangle, text and an arrow, which then move separately.

```json
{ "id": "op_20", "op": "callout", "rect": [600, 120, 260, 70], "tail": [480, 210],
  "text": "Click Save", "size": 18, "color": "#FFFFFF", "bg": "#FF3B3B",
  "radius": 8, "style": "bubble" }
```
- Styles: `bubble` (rounded box with a curved tail) and `box` (square, straight tail).
- The tail tip has its own handle. Moving the box keeps the tip where it is.
- The box grows to fit the text, and text goes through the input method, so Vietnamese works the same as AC7.

### 2. Step badge upgrades (extends ANN-1)
This is what makes step badges useful for documentation, not only bug reports.
- **Badge with a label:** an optional `text` next to the badge ("1  Open Settings"), so one op replaces a badge plus a text.
- **Numbering style:** `1, 2, 3`, `A, B, C` or `a, b, c`, plus a start number, so a second screenshot in a guide can continue from 5.
- **Reorder:** a small list in the panel to drag steps into a new order. Today the order is fixed by when each badge was created.

```json
{ "id": "op_21", "op": "step", "at": [400, 200], "n": 1, "size": 28, "color": "#FF3B3B",
  "style": "number", "start": 1, "text": "Open Settings" }
```
`style`, `start` and `text` are optional, so older manifests still render the same.

### 3. Spotlight
Dims the whole screenshot except one or more areas, so the eye goes straight to what matters. Snagit has this, and it's the most-used effect in documentation screenshots.

```json
{ "id": "op_22", "op": "spotlight", "shapes": [
    { "shape": "rect", "rect": [380, 160, 300, 90], "radius": 8 },
    { "shape": "ellipse", "rect": [900, 40, 60, 60] } ],
  "dim": 0.6, "mode": "dim" }
```
- One op holds several holes, so there's a single dim layer rather than dark layers stacking on top of each other.
- `mode: "blur"` blurs the outside instead of darkening it. It follows the same op-order rule as ANN-2.
- Only one spotlight per image. Adding a second shape adds a hole to the existing op.

### 4. Magnify (loupe)
Shows a zoomed copy of a small area, such as a tiny icon or a 10 px setting, in a circle or rectangle placed nearby, with an optional line to the source. Snagit and ShareX both have it.

```json
{ "id": "op_23", "op": "magnify", "source": [1210, 14, 40, 24], "at": [1000, 120],
  "zoom": 3, "shape": "circle", "border": "#FFFFFF", "connector": true }
```
- It renders from `original.png`, so it stays sharp. It doesn't upscale the already-annotated image.
- Ops listed before it appear inside the loupe, the same as blur.

### 5. Stamps (rest of ANN-4, optional)
Built-in vector icons: ✓, ✗, !, ?, and maybe a "Before" / "After" label. They're cheap to build and useful for review screenshots. Pasted image overlays can stay in the P2 bucket.

### Example acceptance criteria
- **Spotlight:** given a spotlight with two holes at `dim: 0.6`, the pixels outside both holes have 40% of their original brightness, the pixels inside are unchanged, and the render matches the golden image within 1%.
- **Callout:** moving a callout's box leaves its tail tip at the same image coordinates.
- **Steps:** given steps with `style: "letter"` and `start: 3`, the badges read C, D and E. Deleting D relabels the last one to D.
- **Magnify:** at zoom 3, the loupe is sharp at 2× export, because it's rendered from the original pixels and not upscaled.

### Agent angle
This is worth a line in the spec. With these ops, an agent can turn "record bug → annotate → GitHub issue" into a polished result: a spotlight on the broken control, a callout explaining it, and numbered steps to reproduce. Later, the step-guide feature can place step badges automatically from the click track.
